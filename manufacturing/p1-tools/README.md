# P1 manufacturing review kit — not an order release

From the repository root, with Python 3.9+ and KiCad CLI **10.0.8** on PATH (or set `KICAD_CLI` to the executable):

```sh
python3 -B manufacturing/p1-tools/test_export.py
sh manufacturing/p1-tools/review.sh hardware/p1/p1.kicad_pcb \
  manufacturing/p1-candidate/procurement.csv p1-review-new
```

Use a new output directory. The mapping must match the frozen schematic by exact reference and MPN. Update verified procurement evidence and rerun the entire command after any source or supplier change; do not patch the delivered BOM or reuse previous CAM. R11 is checked by re-reading the grouped output. A different R11 requires explicit electrical and purchasing review and an updated gate, not a manual override.

Only the unchanged saved project snapshot supplies the ZIP, BOM, CPL, placement drawings and saved-board DRC. Two successive disposable refill/saves produce reference copper plots for `cam-inspection.json`; neither enters fabrication.zip. The reader compares aperture definitions, flashes, segments and region paths (and their net area) in physical units. It checks the delivered ZIP against the P1 mechanical outline, drills and SMT features. This is not a vendor viewer or DFM check. A changed region still blocks release even when DRC passes. `review.json` binds the saved PCB, schematic, procurement mapping, BOM, CPL and ZIP; `SHA256SUMS` binds generated files. When promoting a rebuild, review differences, refresh the human-readable HOLD notes and regenerate their checksum too. Publish only reviewed candidate files, never staging, scratch, or an incomplete run.

## Stackup and first-article checklist (proposal; sign against final P1)

- [ ] Single PCB, not panelized. P1 staging board uses four copper layers. Proposed four-layer FR-4, 1.6 mm finished, 1 oz outer copper each side, green mask, white silkscreen, lead-free HASL unless pad flatness/connector process requires ENIG. Layer order: top silk / mask / F.Cu / dielectric / In1.Cu / core / In2.Cu / dielectric / B.Cu / mask / bottom silk. Paste is stencil data, not laminate. Confirm inner copper weight (proposal 0.5 oz), dielectric thicknesses and JLC standard build with designer. No controlled impedance or special via process assumed. Verify finish, via tenting, smallest drill/annular ring, trace/space and mask dams against the selected JLC service; record actual selections. Compare measured outline to mechanical release, not the provisional 38 × 34 mm target.
- [ ] Open **the ZIP contents** in an independent Gerber viewer. Confirm actual layer count, closed outer contour, cutouts and dimensions; verify drills/slots/pad centers, NPTH versus plated, copper edge clearance, mask/paste openings, legible polarity and connector pin labels. No drawing frames, dimensions, fabrication layers or drill maps in ZIP. Disabled paste/silk sides are reported, not fabricated as dummy files. If any disabled layer is needed, fix source. Reject copper-only links with unwanted paste bridges.
- [ ] Record top and bottom JLC assembly counts, separately hand-fitted parts and accessories. DNPs excluded from BOM and CPL; review each `omitted_board_refs` against signed build intent. Copper-only open solder links are not purchased: confirm JP1/JP2 open in default low build and select only the electrically approved pair for high build. Do not confuse placement exclusions with removal of copper or paste. No automatic THT filtering; explicitly negotiate THT or document hand fit before quote. Housings, crimps, harness, fasteners, enclosure and external adapter are separate system BOM items.
- [ ] Both sides use **absolute board coordinates, mm, top-view axes**; never negate bottom X or translate CPL independently of CAM. Each CPL origin is checked against the footprint `(x, -y)` and physical layer. That verifies the CAD anchor, **not** the pickup centroid. Match two widely separated asymmetrical features to Gerbers per populated side; confirm empty side if none. Bottom SVG is mirrored for a human looking from below, not a source of machine coordinates. Angles are KiCad values modulo 360, not guaranteed JLC library zeroes.
- [ ] Review each populated ref in JLC placement preview against the correct side's assembly drawing, pad numbers and manufacturer top-view package drawing: capacitor polarity stripe, Q1 gate/source/drain, regulator pin 1 and tab, comparator/switch pin 1, JST pin 1 and mating direction. Check connector body centroid vs pad-1 origin; a correct angle at a wrong anchor is still wrong. Record ref/side, original and approved XY/angle, pin-1 evidence, reviewer and preview revision; correct by verified part-specific translation/rotation and repeat overlay. Never apply a blanket bottom transform. No preview or unknown orientation = hold.
- [ ] Keep design approval, supplier DFM and stock confirmation, first-article test approval and production release separate. See [acceptance guide](acceptance.md) and [adapter shortlist](supply.md).

Official JLCPCB references: [Gerber/drill settings and layer selection](https://jlcpcb.com/help/article/how-to-generate-gerber-and-drill-files-in-kicad-9), [KiCad BOM and CPL fields](https://jlcpcb.com/help/article/how-to-generate-the-bom-and-centroid-file-from-kicad), [placement coordinates and CCW degrees](https://jlcpcb.com/help/article/pick-place-file-for-pcb-assembly), [current manufacturing capabilities](https://jlcpcb.com/capabilities/pcb-capabilities). No upload or order is part of this workflow.
