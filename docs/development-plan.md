# 230 V Mains-Powered LED Candle Supply — Development Plan

1. **Align KiCad versions.** The Windows editor and NAS CLI both report KiCad 10.0.8. Use that version for ERC and exports.
2. **Review A0.** A0 is a DC distributor with five branch protection placeholders. It accepts an externally set 3.0 V or 4.5 V bench supply. The repository includes the editable schematic, its ERC report, and an SVG preview of the same revision.
3. **Publish the preview.** Push the checked files to the private `JaJuRiba/230v-led-candle-power-supply` repository using a repository-scoped SSH deploy key. Verify that the remote branch matches the local commit and that GitHub renders the README preview. Clone the repository on the PC and open the schematic in KiCad.
4. **Design the low-voltage prototype.** Define input tolerances and regulator headroom, select the voltage-setting method, and design overvoltage, reverse-polarity, and individual branch protection. Leave the final PCB outline open. Determine current and voltage limits for the actual candle model before committing to final values.
5. **Test on the bench.** Use an isolated, current-limited supply and the reference loads documented in the README. Check no load, one and five outputs, power-up, load steps, and single-branch faults. Verify polarity, current peaks, timer behavior, and restart for the actual candles before installing them. Record results in `docs/test-results.md` when measurements exist.
6. **Check the enclosure in parallel.** Confirm the usable internal profile from CAD or an uninstalled KAISER 1555-05. Include covers, screw bosses, terminals, wiring, and enclosures in the fit study. A qualified electrician must review electrical separation, protection, and thermal behavior before any mains integration. An external supply remains an option.
7. **Prepare manufacturing only after design review and bench testing.** Choose and verify actual footprints and LCSC part numbers, run PCB DRC, and review the Gerbers, BOM, and placement data before placing a JLCPCB order.
